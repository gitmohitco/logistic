# Logistics Control Tower 🚚✈️🚢

Enterprise Multi-Modal Supply Chain & Fleet Telematics Platform built with React, Vite, TypeScript, and Node.js backend.

## Features
- **Real-Time GPS Telematics & Fleet Simulation:** Live map tracking 500+ multi-modal freight vehicles (Ground, Air, Maritime) with 60 FPS Canvas rendering.
- **Critical Escalation War Room:** Incident management with AI Root Cause Analysis (RCA) and mitigation microflows.
- **Carrier Portal & Collaborative Re-planning:** Secure carrier workspace for proposing ETA adjustments and updating vehicle tracking status.
- **Bulk Shipment Tracking:** High-speed parcel and container lookup with instant status breakdowns.
- **Role-Based Access Control (RBAC):** Customized dashboards for Administrators, Analysts, Dispatchers, Supervisors, and Customers.
- **Glassmorphism & Apple Glass Themes:** Tailored modern design system with dynamic palette selection (Wine, Frost Green, Amber, Emerald, Royal Blue).

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Install frontend dependencies
npm install

# Install server dependencies
cd server
npm install
cd ..
```

### Running Locally
```bash
# Start frontend application
npm run dev

# Start backend server (optional)
cd server
npm run dev
```
